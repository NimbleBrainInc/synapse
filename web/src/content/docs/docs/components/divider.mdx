`Divider` draws a one-pixel rule to separate sections or inline items. Its color
comes straight from the host's border token, so it always matches the surrounding
chrome and follows light and dark. It is decorative (`aria-hidden`) — a visual
break, not a semantic separator. The preview below is the real component from
`@nimblebrain/synapse/ui`, live.

```tsx
import { Divider } from "@nimblebrain/synapse/ui";

<Stack gap={12}>
  <Text>Above the rule</Text>
  <Divider />
  <Text>Below the rule</Text>
</Stack>;
```

## Orientation

A horizontal divider spans the full width of its container. A vertical divider
stretches to the height of its flex row, so it is handy for separating inline
items — give it an explicit height when the row has no intrinsic one.

```tsx
<Inline gap={12}>
  <Text tone="muted">Drafts</Text>
  <Divider orientation="vertical" style={{ height: 16 }} />
  <Text tone="muted">Sent</Text>
</Inline>
```

## Props

`Divider` extends the native `HTMLAttributes<HTMLDivElement>`, so `className`,
`style`, `id`, and every other div attribute pass straight through.

| Prop | Type | Default |
| --- | --- | --- |
| `orientation` | `"horizontal"` \| `"vertical"` | `"horizontal"` |
| `…rest` | `HTMLAttributes<HTMLDivElement>` | — |
