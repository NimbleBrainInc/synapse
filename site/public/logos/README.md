# Host logos

Marks used to identify the hosts a Synapse app renders in. They are the property
of their respective owners and are used here for identification only (nominative
use); their inclusion does not imply endorsement.

- `openai.svg`, `anthropic.svg`, `anthropic-ink.svg` — OpenAI / Anthropic.
- `vscode.svg` — the Visual Studio Code mark.
- `nimblebrain.svg` — NimbleBrain (the self-hosted runtime).
